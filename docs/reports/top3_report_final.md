# K-제과 수출 유망국 추천 리포트 — 신규 개척형 TOP3 (검토 수정본)

- 작성 방식: LLM(HyperCLOVA X HCX-007) 작성 → 코드 숫자 대조 → **검토자 수정** (2026-11-03, 트렌드 축에 Google Trends 'K-pop' 추가 후 재생성)
  - 원본: `top3_report.md`. 숫자와 근거 번호는 손대지 않았고, 근거와 다른 표현·어색한 문장만 고침
  - 영국: 숫자만 나열된 문장("1.4%[13]과 2/100[14] 지표는…")을 지표 이름과 함께 풀어 씀, LLM이 붙인 메모 문단 삭제, 관세 0%에 근거의 '검토 필요' 표시
  - 싱가포르: 근거 없는 "수입 의존적 소비 패턴" 삭제 / 네덜란드: '현지 시장 관심도' → 'Pepero' 검색 관심도
- 모든 수치는 score.py 출력(data/scores*.csv, drivers*.json, sensitivity*.csv)에서만 가져옴
- 두 트랙: 2025년 한국 제과 수출 2,000만 달러 이상인 기존 주력시장(베트남, 필리핀, 중국, 일본, 대만, 홍콩, 미국, 캐나다, 호주)은 '확대형'으로 분리하고, 나머지에서 '발굴'할 신규 개척형 TOP3를 뽑음. 확대형 우선순위는 맨 아래 참고
